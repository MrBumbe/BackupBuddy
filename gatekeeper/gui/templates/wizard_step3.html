Choose where BackupBuddy will store encrypted fragments from cluster members.

One absolute path per line. The installer creates /var/lib/backup-buddy/storage with the correct ownership — no extra steps needed. For a path on a separate disk (e.g. /mnt/buddy-storage), create it first: sudo mkdir -p /mnt/buddy-storage && sudo chown backupbuddy:backupbuddy /mnt/buddy-storage.
