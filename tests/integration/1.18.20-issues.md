## ISSUE-005
Step: D (Björn wizard step 3)
Symptom: Wizard step 3 storage-path auto-create (1.18.3 fix) failed on Björn and Carina with "Could not create directory '/mnt/buddy-storage'" because /mnt is root-owned 755 and the backupbuddy service user (uid=999) lacks write permission on /mnt. The 1.18.3 fix only works when the parent directory is already writable by the service. On Anders, /mnt/buddy-storage already existed (from VM 101 clean-ubuntu snapshot taken after a previous wizard run).
Blocking: no — pre-created /mnt/buddy-storage with correct chown on Björn and Carina as a workaround. INSTALL.md §4 Step 3 should note that the parent directory must be writable (e.g., use /var/lib/backup-buddy/storage which is already service-user-owned, or pre-create the directory manually).
