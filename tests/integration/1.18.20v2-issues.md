## ISSUE-002
Step: F1 (Agent install + first start on all three LXCs)
Symptom: Agent failed with `CRITICAL — Configuration error: Backup path does not exist: '/root/backup-test'`
even though the path existed. Actual cause: `/root` is mode 0700 so the `backupbuddy` service user
cannot traverse into it, but the error message says "does not exist" rather than "permission denied".
Root cause: `agent/config.py` path validation uses `os.path.isdir()` which returns False for
inaccessible paths, giving a misleading "does not exist" message instead of a permissions error.
Workaround: `chmod 711 /root` on each test LXC so backupbuddy can traverse (test environment only).
Blocking: no — workaround applied. Production users are unlikely to back up paths under /root.
Fix needed: validate path accessibility as the service user and report a clear permission error.
