## LOG-1 | agent | message | Upload failure message missing file name

**Component:** agent (`__main__`)
**Type:** Logging improvement
**Observed:** 1.26.3 — L3 disk guard test
**Log line:** `ERROR — Failed to upload file: OSError`
**Expected:** `ERROR — Failed to upload file disk-guard-test.bin: OSError (HTTP 507 — insufficient disk space)`
**Impact:** Non-technical user cannot tell which file failed without cross-referencing GK log.
**Resolution:** Defer to post-sim task — structural change (add file name and HTTP status to error message).

## LOG-2 | gatekeeper | logger-name | Multiple modules log as `__main__`

**Component:** gatekeeper (multiple modules)
**Type:** Logger name hygiene
**Observed:** 1.26.4 — Q5 logging audit
**Log line:** `INFO — __main__ — ...` (several modules use `logging.getLogger(__name__)` but are invoked as `__main__`)
**Expected:** Logger name should reflect the module path (e.g. `gatekeeper.main`, `gatekeeper.verify.nightly`)
**Impact:** Log filtering by component name is unreliable; `?component=__main__` matches unrelated modules.
**Resolution:** Defer to post-sim task — structural change (ensure every module is imported, not run directly).
